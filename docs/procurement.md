## 三、接线与安全铁律

1. 舵机 5V **独立供电**，严禁从树莓派/STM32/USB 取电；8 路堵转峰值可达约 10A。
2. 舵机电源 GND、STM32 GND、Pi GND **必须共地**。
3. 上电前用万用表确认 5V 极性和电压，再插舵机；串保险丝。
4. 不要带电热插拔舵机总线；先单舵机、后整手。
5. STM32 PA9 是 5V 容忍脚，可直接接总线 DATA；若响应不稳再加电平转换。
6. Phase 1 没有独立看门狗/保护，测试时必须有人看护，并准备直接断舵机 5V 的急停手段。
